# Limitations

Phase 2D syntax supports the Phase 2B component, prop, form and conditional syntax plus file-local classes with literal fields, computed values and parameterless actions; typed non-empty list state; keyed iteration; append/remove/move operations; and component init/cleanup blocks. Phase 3A.1 runtime updates add compiler-marked static bindings and synchronous transactional rollback without changing that syntax. Reactive bindings subscribe only to values they read. Child props refresh without remounting; committed keyed records retain DOM identity, focus, selection and child-local state when structural preparation aborts.

Structural preparation is reversible. Once prepared DOM changes commit, removed-scope cleanup is irreversible: cleanup failures are reported as post-commit errors and committed state remains committed. If rollback cleanup or reactive recovery fails, participating components are disabled and the combined failure is reported. Transactions do not cover asynchronous work or arbitrary side effects in trusted host JavaScript, getters, proxies, or mount/cleanup functions. Resource limits for hostile source and runtime collection sizes remain unimplemented.

Classes have no inheritance, access modifiers, custom constructors, static members or arbitrary methods. List item types are inferred from a non-empty literal; empty typed lists, filtering, sorting expressions, indexes and nested collection mutation are deferred. Actions and handlers accept only validated assignments, class actions and list operations. `or`, ordering comparisons, broader operators, additional event members and controls, arbitrary calls, component children/slots, routing, SSR, plugins, LSP/editor extensions, native targets and a registry remain unsupported. Numeric literals are nonnegative safe integers; runtime numeric props and arithmetic may be negative but must remain finite safe integers. Development uses full reload after source edits; state-preserving HMR and generated JavaScript source maps are deferred. Packages remain private/unpublished.

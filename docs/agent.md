Do not invent syntax. The beta supports documented `class` fields, computed values, parameterless actions, typed list literals, `for … in … key=…`, list append/remove/move, and component init/cleanup blocks. The beta adds one default `slot` for parent-provided layout content; named and fallback slots remain unsupported. Handlers remain closed typed statements; application JavaScript is not accepted. Request founder approval before adding operators, methods, event members, controls, inheritance, asynchronous effects, or other executable forms. Use the selected manager commands in the root AGENTS.md. npm: npm run check and npm run build; pnpm: pnpm run check and pnpm run build. See [package managers](package-managers.md).
